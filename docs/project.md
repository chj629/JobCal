# JobCal 제품 기획서

## 1. 프로젝트 개요

### 프로젝트명

`JobCal`

### 프로젝트 목적

일본 취업을 준비하는 학생들은 보통 30~100개 이상의 기업에 지원하며, 기업마다 일정과 전형 방식이 달라 관리가 어렵습니다.

현재 대부분은 Excel, Notion, 메모장 등을 이용해 직접 정리하고 있으며, 메일과 기업 마이페이지를 반복해서 확인해야 합니다.

JobCal는 이러한 과정을 하나의 웹 서비스에서 관리할 수 있도록 하여 다음을 돕습니다.

- 취업 준비에 필요한 반복 입력 시간 감소
- 지원 현황의 체계적인 관리
- 중요한 일정과 결과 발표일 누락 방지
- 많은 기업을 지원해도 빠르게 확인할 수 있는 환경 제공

---

## 2. 문제 정의

- 지원 기업이 많아질수록 전체 현황을 파악하기 어렵다.
- 기업 마이페이지를 일일이 방문해야 한다.
- 메일을 하나씩 확인해야 한다.
- 면접, 제출 마감, 결과 발표일을 놓칠 수 있다.
- Excel 또는 Notion을 계속 직접 수정해야 한다.
- 기업별 로그인 정보와 담당자 정보를 따로 관리해야 한다.
- 기업별 면접 준비 내용과 메모가 여러 곳에 흩어진다.

---

## 3. 해결 방법

한 기업에 대한 모든 정보를 하나의 상세 화면에서 관리합니다.

- 기업 기본 정보
- 현재 진행 단계
- 전체 전형 타임라인
- 일정 및 결과 발표일
- 마이페이지 바로가기
- 로그인 정보
- 담당자 연락처
- 자유 메모
- 참고 링크

MVP에서는 수동 입력과 관리 경험을 먼저 완성합니다.

AI 자동 입력 기능은 웹 MVP가 안정된 이후 추가합니다.

## 4. 핵심 사용자

- 신졸 채용에 지원하는 외국인 유학생
- 30~100개 이상의 기업에 지원하는 취업 준비생
- Excel이나 Notion으로 취업 현황을 직접 정리하는 사용자

## 6. MVP 주요 기능

### 6.1 기업 관리

- 기업 추가
- 기업 조회
- 기업 수정
- 기업 삭제
- 기업 검색
- 기업 정렬
- 우선순위 설정

우선순위

- 높음
- 보통
- 낮음

기업 목록에서는 다음 정보를 표시합니다.

- 기업명
- 현재 전형 단계
- 상태
- 다음 일정
- 우선순위
- 최종 수정일
- 결과

---

### 6.2 기업 결과

기업 전체의 현재 상태를 나타냅니다.

- 진행 중
- 내정
- 입사
- 불합격
- 지원 취소

결과는 색상과 Badge를 함께 사용합니다.

---

### 6.3 전형 관리

기업 생성 시 기본 전형이 자동 생성됩니다.

1. 엔트리
2. 설명회
3. ES
4. Web 테스트
5. 코딩 테스트
6. 1차 면접
7. 2차 면접
8. 최종 면접

사용자는 기업별로 전형을 자유롭게 관리할 수 있습니다.

- 전형 추가
- 전형 삭제
- 전형 순서 변경
- 전형 이름 수정

회사마다 필요 없는 단계는 삭제하거나, 새로운 단계를 추가할 수 있습니다.

---

### 6.4 전형 상태

각 전형은 다음 상태를 가집니다.

- 대기
- 해야 함
- 일정 확정
- 완료

예시

설명회

- 대기 → 설명회 안내 대기
- 일정 확정 → 설명회 일정 확정
- 완료 → 설명회 참석 완료

ES

- 대기 → 제출 요청 대기
- 해야 함 → 제출 필요
- 완료 → 제출 완료

면접

- 대기 → 면접 연락 대기
- 일정 확정 → 면접 일정 확정
- 완료 → 면접 완료

### 6.5 일정 관리

각 단계에 다음 정보를 등록할 수 있습니다.

- 일정 날짜
- 시작 시간
- 종료 시간
- 결과 발표 예정일
- 마감일
- 장소
- 온라인 링크
- 메모

대시보드 표시:

- 오늘 해야 할 일정
- 오늘 결과 발표
- 가까운 D-Day
- 마감 임박 일정

### 6.6 마이페이지 정보

- 마이페이지 URL
- 로그인 ID
- 비밀번호
- 로그인 메모

보안 원칙:

- 비밀번호는 기본적으로 숨김 처리
- 평문 저장 금지
- 실제 구현 전에 암호화 방식 결정

### 6.7 담당자 정보

담당자 정보는 선택 입력 기능입니다.

관리 가능한 정보

- 담당자 이름
- 이메일
- 전화번호
- 소속 또는 역할
- 메모

기본적으로 접힌(Collapsible) 상태로 표시하며,
필요한 경우에만 펼쳐서 입력 및 수정할 수 있습니다.

### 6.8 메모

예시:

- 면접 질문
- 기업 특징
- 준비할 내용
- 자기소개서 제출 내용
- 참고 링크
- 설명회 메모

### 7.3 기업 상세

상세 페이지는 **"요약 → 선택 → 상세"** 구조를 사용합니다.

#### 1. 상단 정보

좌측

- 현재 전형
- 다음 일정
- 지원 우선순위
- 기업 홈페이지
- 기타 기본 정보

우측

**마이페이지**

- URL
- ID
- PW
- 복사
- 비밀번호 보기/숨기기

마이페이지는 실제 사용 빈도가 높으므로 상단에서 바로 접근할 수 있도록 합니다.

---

#### 2. 전형 진행

전형은 세로 리스트가 아닌 **가로 진행바(Timeline)** 형태를 사용합니다.

예시

```
○──○──●──○──○──○──○──○

엔트리 설명회 ES Web 1차 2차 최종
```

- 완료
- 현재 진행
- 대기

상태를 색상으로 구분합니다.

---

#### 3. 전형 상세

전형 진행바 자체가 탭(Tab) 역할을 합니다.

사용자가 전형을 선택하면 아래 영역이 해당 전형의 상세 내용으로 변경됩니다.

관리 가능 항목

- 전형 이름
- 전형 상태
- 순서 변경
- 삭제

---

#### 4. 일정

선택한 전형의 일정만 표시합니다.

표시 항목

- 일정
- 마감
- 결과 발표

기능

- 일정 추가
- 일정 수정
- 일정 삭제

---

#### 5. 담당자 정보

담당자 정보는 기본적으로 접힌(Collapsible) 상태로 표시합니다.

필요한 경우 펼쳐서 관리할 수 있습니다.

관리 가능 항목

- 담당자 이름
- 이메일
- 전화번호
- 부서 또는 직책
- 메모

---

#### 6. 메모

기업 관련 메모를 자유롭게 작성합니다.

---

사용자는 최대 3번의 클릭 안에 모든 기업 정보에 접근할 수 있어야 합니다.

---

### 7.4 기업 등록

기업 등록 시에는 필요한 정보만 입력합니다.

입력 가능한 항목

- 기업명 (필수)
- 우선순위
- 기업 전체 상태
- 기업 홈페이지
- 마이페이지 URL
- 마이페이지 ID
- 마이페이지 PW
- 메모

※ 기업명을 제외한 모든 항목은 선택 입력입니다.

담당자 정보는 기본적으로 접힌 상태의 선택 영역으로 제공합니다.

담당자 정보

- 담당자 이름
- 담당자 이메일
- 담당자 전화번호
- 부서 또는 직책

사용자가 `담당자 정보 추가`를 누르면 입력창이 펼쳐집니다.

기업 생성 시 기본 전형 8개는 자동 생성됩니다.

초기 등록에서는 전형이나 일정을 입력하지 않습니다.

전형과 일정은 기업 생성 후 기업 상세 페이지에서 관리합니다.

## 11. MVP 성공 기준

1. 사용자가 로그인할 수 있다.
2. 기업을 추가하고 수정하고 삭제할 수 있다.
3. 기업을 검색하고 정렬할 수 있다.
4. 기업별 전형 단계를 관리할 수 있다.
5. 단계별 일정과 결과 발표일을 저장할 수 있다.
6. 대시보드에서 오늘 일정과 D-Day를 확인할 수 있다.
7. 마이페이지, 담당자, 메모를 기업별로 관리할 수 있다.
8. 전형 진행바를 통해 각 전형을 직관적으로 관리할 수 있다.
9. 선택한 전형의 일정만 빠르게 확인할 수 있다.
10. 100개 이상의 기업도 빠르게 확인할 수 있다.
11. 데스크톱과 모바일 브라우저에서 사용할 수 있다.
12. Excel이나 Notion보다 관리가 편하다고 느낄 수 있다.
